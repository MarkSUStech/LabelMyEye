# LabelMyEye — 眼底光凝标注工具

面向眼底照片的智能标注工具：**点击/框选 + AI 分割** 自动完成视盘、黄斑与 DR 光凝相关结构的标注，专为糖尿病视网膜病变（DR）激光光凝场景设计。兼容 LabelMe JSON 格式；支持单图标注与 **Before + After** 双图配准。

## 功能总览

| 功能 | 说明 |
|------|------|
| AI 框选分割 | 拖框圈住视盘/黄斑 → MobileSAM 本地分割 → 自动拟合圆 |
| DR 五结构自动生成 | 视盘、黄斑、血管弓区绿椭圆、后极部橙卵圆、光凝敏感区紫肾形 |
| Project Files 批量面板 | 打开文件夹缩略图浏览，单击换图，✓ 标记已标注数量 |

| 平滑变形拖拽 | 密集多边形拖一点，周边点高斯平滑跟随 |
| DR 参数可调 | 所有 PD 扩展量、凹口深度/平滑度图形界面实时调整 |

| 双图配准 | Before + After 同时加载对齐，导出 Before 坐标系标注 |
| Undo / Redo | Ctrl+Z / Ctrl+Y |
| 完全离线 | AI 推理本地运行，不上传任何数据 |

## 安装

要求：Windows / Python 3.10+

```bash
git clone https://github.com/MarkSUStech/LabelMyEye.git
cd LabelMyEye
pip install -r requirements.txt
```

或直接双击 `启动LabelMyEye.bat`。

> AI 功能还需要 SAM 模型文件——见下一节的一键安装。

---

## 第一步：安装 SAM 模型（一键）

1. 启动软件，打开菜单 **AI (DR) → 一键安装 SAM 模型…**
2. 点击 **Yes**，软件自动从网络下载模型（约 45 MB，一次性）到 `assets/models/`
3. 提示"安装完成"后即可使用

下载失败时的备选方案：

- 本机装有 PyTorch：重新点击安装并选择 **No**，改用本地导出（`scripts/prepare_sam_onnx.py`）
- 也可以手动运行 `python scripts/prepare_sam_onnx.py`
- 或从项目 Release 手动下载两个 onnx 文件放入 `assets/models/`

模型来源 [MobileSAM](https://github.com/ChaoningZhang/MobileSAM)（Apache-2.0），导出为 ONNX 后由 [onnxruntime](https://onnxruntime.ai) CPU 推理，**完全离线，不上传任何数据**。

---

## 第二步：打开图片（单个 / 批量文件夹）

- **单张**：`File → Open Image…`（Ctrl+O 位置在 File 菜单）
- **批量（推荐）**：左侧 **Project Files** 面板 → **Open Folder** 选择文件夹
  - 支持本地文件夹和网络盘路径（如 `\\服务器\共享\病例`）
  - 缩略图列表，**单击任意图片即切换标注**
  - 文件名前的 **✓** 表示该图已保存过 JSON
  - 右上角 **⟳** 刷新；软件会记住上次打开的文件夹

---

## 第三步：AI 框选标注（视盘 + 黄斑）

1. 菜单 **AI (DR) → 框选标注视盘**（Ctrl+1）
2. **按住鼠标拖出一个框，把视盘完整圈进去**，松开
   - 首次会先编码整张图（约 1–3 秒，状态栏有提示），之后每次拖框 <0.2 秒
   - 分割结果自动拟合为红色 `optic` 圆
3. 菜单 **AI (DR) → 框选标注黄斑**（Ctrl+2），同样拖框
   - 生成蓝色 `macular` 圆（圆心取分割质心，半径按 0.85×视盘半径约定）
4. **两个圆齐备的瞬间，绿/橙/紫三个派生结构自动生成**：

| 结构 | 颜色 | 含义 |
|------|------|------|
| `macular_area` | 绿 | 与视盘、黄斑两圆相切的血管弓区椭圆 |
| `posterior_pole_boundary` | 橙 | 后极部边界：绿椭圆边缘外扩（颞 2PD / 鼻 1PD / 上下 2PD） |
| `central_inner` | 紫 | 光凝敏感区：后极部让出上下激光安全区 + 视盘包绕 ≥1PD |

框选位置不满意？重新拖框即可覆盖。想调整大小？见下节编辑。

## 第四步：理解五个自动生成的结构

```
optic(红) + macular(蓝)          ← AI 分割输入结果
   ↓
macular_area(绿椭圆)              ← 与两圆同时相切
   ↓
posterior_pole_boundary(橙)       ← 绿椭圆边缘外扩：颞侧2PD·鼻侧1PD·上下2PD
   ↓
central_inner(紫)                 ← 后极部让出上下激光安全区 + 视盘包绕≥1PD
```

完整的数学定义、公式与推导见 **[docs/DR算法说明.md](docs/DR算法说明.md)**
（LaTeX 排版版：[`docs/DR光凝标注派生结构算法说明.pdf`](docs/DR光凝标注派生结构算法说明.pdf)）。

简言之，紫色敏感区 = **后极部整体 − 上下两个激光安全区 + 视盘包绕帽**：
- 颞侧与鼻侧贴住后极部（这些区域紧邻需要保护的结构）
- 上下两个方向让开——那是 PRP 实际打激光的地方
- 视盘和黄斑整个被包在保护区内

## 第五步：人工微调

**所有 AI 生成的形状都是普通可编辑形状**：

- 视盘 / 黄斑 / 后极部：**原生圆形**——2 个控制点，拖圆心移动、拖边缘点改大小
- 绿椭圆：**原生椭圆**——3 个控制点（中心、长轴端、短轴端）
- central_inner：96 点多边形，支持**平滑变形**——拖动一点，周边点按高斯权重平滑跟随
- 改了视盘/黄斑后，按 **Ctrl+3** 用新圆重新派生绿/橙/紫
- 凹口的深度、平滑度、PD 扩展量都在 `AI (DR) → DR 参数…` 里调，改后 Ctrl+3

**标注质量控制**：AI 结果的 `description` 标记为 `auto`；分割置信度低时标记 `auto(low-conf)` 并在状态栏提醒——这类形状请务必人工复核后再保存。

## 第六步：保存

- `Ctrl+S` 保存为标准 LabelMe JSON（与图片同目录、同名）
- 保存后 Project Files 面板中该图自动打上 **✓**
- JSON 兼容 LabelMe：可在 LabelMe 中继续编辑（圆形在 LabelMe 中也是原生的）

## 双图配准工作流（术前/术后）

1. `File → Quick Dual from Folder…` 选择含 before/after 图片的文件夹
2. 调 Before 透明度，进入 **Register Before** 模式对齐解剖标志（拖动平移、Ctrl+滚轮缩放、Ctrl+Shift+滚轮旋转）
3. 在 After 层做 AI 标注
4. `Ctrl+E` 把标注按配准变换到 Before 坐标系导出
5. `Save Dual Project` 保存配准参数（`*.lmye.json`）

## DR 参数详解

`AI (DR) → DR 参数…`（改完按 Ctrl+3 重算派生结构）：

| 参数 | 默认 | 含义 |
|------|------|------|
| 后极部颞侧扩展 | 2.0 PD | 橙卵圆超出绿椭圆颞侧边缘的距离 |
| 后极部鼻侧扩展 | 1.0 PD | 橙卵圆超出绿椭圆鼻侧边缘的距离 |
| 后极部上下扩展 | 2.0 PD | 橙卵圆超出绿椭圆上下边缘的距离 |
| 黄斑半径系数 k_mac | 0.85 | 黄斑圆半径 = k_mac × 视盘半径 |
| 上/下凹陷深度 | 0.50 / 0.46 | 紫色轮廓在该方向的收缩比例 |
| 凹口平滑度 σ | 40° | 凹口与后极部衔接的平滑程度 |

这些默认值由组内 14 例手绘标注最小二乘标定（详见 [算法说明](docs/DR算法说明.md) 第 5 节），修改后只影响之后重算的派生结构，已保存的 JSON 不变。

## 常见问题

**Q：点"一键安装 SAM 模型"下载失败？**
检查网络；或手动把两个 onnx 文件放入 `assets/models/`；本机装有 PyTorch 时可选择本地导出。

**Q：AI 框选后提示"低置信"？**
分割结果可能不准（图像质量差、病变遮挡）。请人工复核拖点修正，或重新拖框。

**Q：AI 菜单是灰的/提示模型缺失？**
`assets/models/` 下没有 onnx 文件，用一键安装或手动放置。

**Q：标签颜色每次启动都不一样？**
旧版问题，现已固定：视盘红、黄斑蓝、血管弓绿、后极部橙、敏感区紫。

**Q：想在另一台电脑用？**
克隆本仓库 + `pip install -r requirements.txt` 即可，模型已包含在仓库中；或复制整个文件夹。
